# Jim McGuinness Demo Script (12 Minutes)
**OneStat GAA Analytics Platform**

## 🎯 THE STORY (Tell → Show → Tell)

**1. Tell – What is it?**
Right now in GAA, data is fragmented. You tag videos in one place, charts and views in another, maybe a spreadsheet for match stats, GPS data in another spreadsheet. Everything's scattered across the season.

OneStat is where all that data accumulates in one place, with an AI layer on top that identifies patterns, outliers, anomalies - what's working, what's not.

**2. Show – The Demo**
Real Dungloe GAA data. Walk through the platform naturally - dashboard insights, live recording workflow, video analysis. Let the features reveal themselves.

**3. Tell – Why does it matter?**
Saves time turning match data into tactical intelligence. Makes complex stats easy to understand. Helps coaches identify what matters without adding more work. Professional depth, accessible infrastructure.

## 🎯 DELIVERY TIPS FOR 12 MINUTES

### Pacing:
- **Don't linger** - show, don't explain exhaustively
- **Let Jim interrupt** - he will, and his questions are better than your script
- **Click through examples** - 2-3 instances of each feature, not just one

### What to Emphasize (let these come up naturally as you demo):
1. **"Data accumulates here with an AI layer on top"** - opening and throughout
2. **"AI learns from your tactical documents in the knowledge base"** - mention in opening, Season Dashboard, and Match Analysis
3. **"Patterns, outliers, anomalies - what's working, what's not"** - when showing AI insights
4. **"Real club match data, not a demo"** - when showing each section
5. **"One analyst, one iPad"** - when showing Match Recording
6. **"What would you want to know from this match?"** - let Jim guide you to what matters

### What NOT to do:
- ❌ Apologize for missing features
- ❌ Get bogged down in technical details
- ❌ Over-promise what's not built yet
- ❌ Bad-mouth competitors

### If Time Runs Over:
**Cut these first (in order):**
1. Video integration in Match Analysis section
2. Player Profiles section (merge into Match Analysis if needed)
3. Opposition tracking detail in Match Recording
4. Tactical planning detail in Match Prep

**Never cut:**
- Opening framing (data fragmentation problem + AI solution)
- Season Dashboard (must show AI insights)
- Match Recording workflow (one analyst, one iPad)
- Match Analysis AI report
- Closing recap (why it matters)
